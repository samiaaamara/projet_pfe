# 🚀 Génération Rapide — PlantUML Online (Sans Installation)

## ✨ Solution la Plus Rapide (Recommandée pour débuter)

Pas besoin d'installer quoi que ce soit ! Utilisez cette méthode pour générer vos diagrammes en 2 minutes.

---

## 📋 Étape 1 : Accéder à PlantUML Online

1. Ouvrir ce lien dans le navigateur :
   👉 **https://www.plantuml.com/plantuml/uml/**

2. Vous devriez voir une zone de saisie de texte PlantUML

---

## 🎯 Étape 2 : Copier-Coller Chaque Diagramme

Pour chaque fichier `.puml` de ce dossier :

### Diagramme 1 — Cas d'Utilisation Global

1. Ouvrir le fichier : `Sprint1_1_CasUtilisation_Global.puml`
2. Sélectionner TOUT le contenu (Ctrl+A)
3. Copier (Ctrl+C)
4. Aller sur https://www.plantuml.com/plantuml/uml/
5. Effacer l'exemple par défaut
6. Coller (Ctrl+V)
7. **Voilà !** Le diagramme s'affiche automatiquement à droite

---

## 💾 Étape 3 : Télécharger l'Image

Clic droit sur le diagramme généré à droite :
```
Clic droit → Enregistrer l'image sous...
```

Ou utiliser le bouton **Download** (PNG) en haut à droite

**Nommer le fichier :** `Sprint1_1_CasUtilisation_Global.png`

## 📄 Intégrer dans Word

### Dans MS Word :

1. **Insérer** → **Image** → **À partir de ce PC**
2. Sélectionner le PNG
3. Cliquer **Insérer**
4. Redimensionner : **largeur ~12 cm**
5. **Centrer** l'image
6. Ajouter une **Caption** (Légende) :
   - Clic droit → **Insérer une légende**
   - Étiquette : `Figure`
   - Numéro : auto
   - Titre : `Diagramme de Cas d'Utilisation Global — Sprint 1`

## ✨ Astuces Utiles

### Zoom et Navigation sur PlantUML Online

- **Molette souris** : Zoom in/out
- **Clic gauche + traîner** : Panner (déplacer)
- **Double clic** : Réinitialiser zoom

### Modifier un Diagramme

Si vous voulez modifier un diagramme pour corriger quelque chose :

1. Le fichier `.puml` reste dans ce dossier
2. Éditez-le avec n'importe quel éditeur de texte
3. Recollez le contenu modifié sur PlantUML Online
4. Régénérez le PNG

## ❓ FAQ Rapide

**Q: Les diagrammes ne s'affichent pas ?**
A: Actualiser la page (F5) et vérifier la syntaxe PlantUML dans la console d'erreur

**Q: Comment ajouter une note ou commentaire ?**
A: Voir la documentation PlantUML pour la syntaxe `note`

**Q: Puis-je modifier les couleurs ?**
A: Oui, via les directives `skinparam` dans le code PlantUML

**Q: Mon diagramme est trop grand, que faire ?**
A: Réduire le zoom PNG en baissant la taille de l'image dans Word
