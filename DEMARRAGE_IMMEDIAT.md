## 🚀 Commencer Maintenant (Choisissez UNE Option)

### ⭐ OPTION 1 : RECOMMANDÉE (5 minutes d'installation, puis 30 min)

**PlantUML Online — Pas besoin d'installer quoi que ce soit**

```
1. Ouvrir : https://www.plantuml.com/plantuml/uml/
2. Ouvrir ce dossier : Diagrammes_PlantUML/
3. Prendre un fichier .puml (ex: Sprint1_1_CasUtilisation_Global.puml)
4. Ouvrir avec bloc-notes
5. Copier le texte complet (Ctrl+A, Ctrl+C)
6. Coller dans PlantUML Online (Ctrl+V)
7. Le diagramme s'affiche
8. Clic droit → Enregistrer l'image sous...
9. Répéter pour les 9 fichiers
```

⏱️ **Temps total : ~30 minutes** pour les 9 diagrammes
📖 **Documentation complète** : [GENERER_RAPIDE_PLANTUML_ONLINE.md](GENERER_RAPIDE_PLANTUML_ONLINE.md)

---

### 💻 OPTION 2 : Installation Locale (30 min installation + 5 min génération)

**Automatise tout d'un clic**

```
1. Télécharger PlantUML JAR
2. Placer dans C:\PlantUML\
3. Ouvrir dossier : Diagrammes_PlantUML/
4. Double-cliquer : GENERER_DIAGRAMMES.bat
5. Les 9 PNG sont créés dans : Images_Sprint1/
```

⏱️ **Temps total : ~35 minutes** (installation + génération)
📖 **Documentation complète** : [GUIDE_PLANTUML_SPRINT1.md](GUIDE_PLANTUML_SPRINT1.md)

---

### 📝 OPTION 3 : VS Code (15 min installation + 10 min par diagramme)

**Pour ceux qui ont VS Code**

```
1. Installer extension "PlantUML" (jebbs.plantuml)
2. Ouvrir un fichier .puml dans VS Code
3. Clic droit → Preview
4. Clic droit → Export Diagram (PNG)
```

⏱️ **Temps total : ~50 minutes** (installation + 9 × export)
📖 **Documentation complète** : [GUIDE_PLANTUML_SPRINT1.md](GUIDE_PLANTUML_SPRINT1.md)
