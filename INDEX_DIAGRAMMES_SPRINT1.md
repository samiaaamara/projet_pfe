## 📞 Dépannage Rapide

### ❌ Les fichiers `.puml` sont vides ou corrompus
**Solution :** Vérifier que vous ouvrez les fichiers de ce dossier :
```
c:\Users\User\Desktop\projet_pfe\Diagrammes_PlantUML\
```

### ❌ PlantUML Online n'affiche rien
**Solution :** 
1. Actualiser la page (F5)
2. Vérifier que vous avez copié le CONTENU COMPLET du fichier
3. Vérifier la console pour les erreurs de syntaxe

### ❌ Les PNG ont mauvaise qualité
**Solution :** Utiliser l'option "Download as PNG" de haute qualité

### ❌ Les PNG sont trop petits/grands
**Solution :** Redimensionner dans Word (clic droit → Redimensionner)
